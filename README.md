# RC27_TEAM-MUX
**Catching Stale Echoes** studies how to identify delayed replayed false targets in an OFDM radar. A repeater can record the radar signal and send it back later, creating a fake target. Because the transmitted data keeps changing, the radar compares the received signal with both current and older OFDM symbols, and then forms range-Doppler maps to detect returns. A return that matches older data indicates a delayed copy and is labelled **stale**, while one that matches only the current data is labelled **current-data consistent**, which does not prove that it is a real target. The method cannot identify replays delayed by no more than the cyclic prefix (2.34 µs in the proposed waveform), may miss slightly longer delays depending on replay power, and cannot recognise replays older than the stored data history. Using changing signals against replay is an established idea, so the aim is to study where this detection method works and fails across delay, signal power and noise; so far, it has been tested only in simulation.
